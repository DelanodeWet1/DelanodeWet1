Error Handling

In the event of unexpected behaviour, the BuyThings web application should return a standard error code to the user and render a safe, simple message explaining the error. For example, if a buyer attempted to create a store (which they do not have permission to do) an error code '403 Forbidden' should be returned and an error message saying 'You do not have the required permission. Please return to the home page.' should be displayed. The user should be told what their next best step should be and directed away from where the error occurred. The same approach will be followed for all standard errors, including attempting to view the details of missing products, calling an unknown url and not being able to execute a SQL query. The key is that the user should not be shown any complex, technical information that could be potentially sensitive such as system details, database queries or stack traces.
